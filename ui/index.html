Input syntax
#topic@agent messagesession — FIFO queued per agent
#topic@agent!N messageadhoc — parallel, last N exchanges as context
#topic@agent! messageadhoc — default 5 exchanges
#topic messageuses sticky agent (last used)
#topictype # to browse & search topics
#topic@type @ to browse agents
Commands — type / to browse
/clearclear session — next message starts fresh (all backends)
/compactcompact session context (resets for Codex; native for Claude)
/stopkill running process for current topic
/stopallkill + drain queue for current topic
/deqdrain entire pending queue
/deq Nremove Nth item (1=first, -1=last)
/filterfilter history by current #topic or #topic@agent
/filter resetclear the active filter
/restartrestart the server
Commands also work without / as exact bare words.
